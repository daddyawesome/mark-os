MARK-OS's "Forest Fieldbook" visual language is inspired by Orbit's
human-centered notebook/sketchbook interface: paper texture, irregular borders,
hard offset shadows, tactile controls, and sticky-note-like dashboard cards.

The MARK-OS implementation is written for its existing FastAPI + Jinja + HTMX
+ Bulma stack. It does not import Orbit's Astro/Preact runtime or Markdown data
architecture.
